## 实验一 letNet模型
利用TensorFlow2.x框架搭建简单网络模型并对图像进行分类：
- 读取MNIST数据集，并对数据进行简单预处理
- 搭建对MNIST数据集进行分类的全连接神经网络模型
- 搭建对MNIST数据集进行分类的LeNet-5卷积神经网络模型
- 训练模型并得到测试集中的分类结果

## 实验二 AlexNet和VGG网络的实现
- 搭建对fashion-mnist数据集进行分类的类AlexNet的模型
- 搭建对fashion-mnist数据集进行分类的类VGG网络的模型

## 实验三 NiN和GoogLeNet的实现
搭建NiN、GoogLeNet和BN层：
- 搭建对fashion-mnist数据集进行分类的NiN模型
- 搭建对fashion-mnist数据集进行分类的GoogLeNet模型

三、实验要求
1.对两个模型进行修改，在网络适当位置添加批量归一化层
2.在实验报告中附程序、并粘贴程序运行结果截图(含每个层输出形状)

## 实验四 ResNet和DenseNet的实现
搭建ResNet和DenseNet网路模型：
- 搭建对fashion-mnist数据集进行分类的ResNet模型
- 搭建对fashion-mnist数据集进行分类的DenseNet模型
